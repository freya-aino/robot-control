# amass

AMASS (amass.is.tue.mpg.de) as an `unverified` `data-source/1` record:
the primary SMPL-X retargeting corpus once licensed, and the exact
layout `services/video-to-smplx` already targets, so the two sources
share one ingestion seam (`robot data import` over AMASS-layout `.npz`).

Blocked on the project owner's registration with MPI and on per
sub-dataset C-07 audits — AMASS aggregates many mocap corpora, each
under its own license, and an audit of the archive is not an audit of
its parts. Nothing is fetched before both exist.
